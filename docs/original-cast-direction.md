# Retain the original cast · 24 October 2026

James rejected the pixel cast candidate: “they look completely different”, followed by “Ok reject and continue”. The problem was a change in identity and character, not a request to replace expressive faces with generic figures. The smaller heads, stretched proportions, simplified faces and forced palette were the wrong interpretation of his desired farming-game style.

## Binding direction

Retain the existing player, Mara and Orin artwork, faces, proportions, skin/clothing colours and familiar silhouettes. The approved Mara and Orin dialogue portraits remain unchanged. Correct world scale, camera, environment treatment, readable text and actual rendering defects without reinterpreting character identity. The live game already retained the original cast; no story-save migration is required.

`view-proof/pixel-cast-v1.png` and `view-proof/pixel-cast.js` are rejected historical evidence. They must not be loaded by the active proof or production game. Their twelve-frame geometry audit was not artistic approval, and passing tests did not make that redesign acceptable. No new character generation or source-image filter is part of this continuation.

## Current proof

The existing `view-proof/` URL has been restored to the original `preparePlayer`/`drawPlayer` and `prepareCharacters`/`drawCharacter` paths, using the shared rig and unchanged source images. The replacement selector and rejected-cast matrix have been removed. A four-panel matrix now shows the actual original cast from front, left, right and back. Movement controls remain the original rig's inspection controls.

The continued environment work is a bounded cottage-scale comparison: Compact120, Balanced128 and Roomier136 world-unit drawing widths. The cottage remains centred on the same threshold; characters retain the same 32-unit height and foot line at every setting. Default Balanced128 is preserved. This illustrates fitting the building around the cast rather than stretching or shrinking people to accommodate a picture. It is not a new live collision footprint or a committed final building design.

The tablet scene is tall enough to inspect the roomier cottage and original cast together at3×; phones start at2×. Larger zoom intentionally crops scenery. Existing sprite animation remains a prototype with its existing quality limitations; this pass does not claim a new walk, new wardrobe or complete animation certification.
