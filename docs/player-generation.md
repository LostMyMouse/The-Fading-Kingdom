# Player parts generation

Built-in imagegen used with the approved Mara and Orin portrait atlases as style references. Final project asset: assets/player/parts.png. Exported copy: outputs/player-prototype/player-parts.png. The actual 887 × 1774 output was measured; crop and layer anchors were reviewed in the assembled renderer.

## Prompt
Use case: stylized-concept. Production modular PAPER DOLL SPRITE PARTS atlas for original cosy farming browser game The Fading Kingdom. References1 and2 define approved warm storybook pixel rendering, round expressive faces and earthy darkbrown outlines; retain that style. A new AGE-NEUTRAL, gender-neutral human adventurer. These are separated CLOTHED game art layers, not full characters and not portraits. EXACT canvas1024x2048, FOUR columns EIGHT rows, equal256x256 cells. Every row contains same part in four views: front, facing LEFT profile, facing RIGHT profile, back. Centre each part in its cell with generous transparent padding. Readable chunky pixel clusters, warm restrained shading, darkbrown outlines, no texture noise/blur. ROW1: ONLY bald head plus short neck, warm medium tan skin, friendly neutral eyes, no beard/makeup, no hair or clothing. Back view only rear of head and neck. ROW2: ONLY short tousled darkbrown hairstyle, hollow transparent opening for face, no face/skin/head/eyes; crown, fringe and side locks, back view full hair. ROW3: ONLY shoulder-length darkbrown hair tied into small low ponytail, hollow transparent face opening, no face/skin/head/eyes, distinct from short style. ROW4: ONLY rustic short-sleeved cream linen button shirt torso, sleeve stubs, no arms/hands/head/legs; frontcollar and3buttons, sideprofile andback. ROW5: ONLY rustic sleeveless moss/brown work vest over cream short-sleeved shirt torso, no head/arms/hands/legs. ROW6: ONLY separated pair of BARE ARMS with hands, shoulder-to-fingertips, matching head skin; each cell has TWO arms with clear gap at verticalcentreline, leftarm onleft half/rightarm onright half. Down relaxed neutral arms, NOT crossed. Profileviews separate near/far arms. No torso/head/clothes. ROW7: ONLY separated pair of darkbrown trousered legs with sturdy brown boots, two distinct legs separated by clear gap atcellverticalcentreline, no torso/head. Short compact legs for chibi RPG character. ROW8: ONLY rustic green soft workcap for eachview, no head/hair/face. Allparts fully fit owncell, no overlap/no extras. Source intended to assemble a big-head small-body topdown3/4 RPG player of about32worldpixels height. SAME camera and pixel density for all parts. Transparent PNG alpha, no scenery, no shadows, NO words/labels/grid/borders or UI. Skin/hair/shirt each separate so engine can recolour each material independently.
