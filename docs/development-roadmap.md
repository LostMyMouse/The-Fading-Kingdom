# Ordered development roadmap

James authorised this order on 28 October 2026. This file tracks work; it is not a claim that a full indie game is complete. Existing artwork identities, free placement, automatic doors, repairable consequences, autonomous NPCs and saved progress remain binding.

1. Movement and art foundation — ACTIVE. Completed incremental passes: continuous passing-pose timing, shared sleeve/hand/tool anchors, material contact, rear-tool backswing rotation, all 16 wardrobe combinations with basket/bundle/axe/pickaxe key poses, and all six separate skin/hair/shirt palette checks on each hairstyle. Still required before declaring this phase complete: final purpose-built animation art replacing the remaining cutout limitations, reviewed assembled against the original cast; continuous motion and full palette-by-outfit action coverage, and physical-device review. Browser layout checks cover 320×740, 390×844, 768×1024 and 844×390 without horizontal overflow. Do not call the current cutout rig an authored production animation sheet.
2. Satisfying village building — QUEUED. Physical construction work, material-to-wall feedback, Mara’s move-in and belongings, clearer placing/arranging and home personalisation. Begin after priority 1’s quality gate.
3. Everyday gameplay polish — QUEUED. Farming/gathering feedback, carrying, object selection, placement preview, journey lengths and material/repetition balance.
4. Kindness and relationships — QUEUED. Listening, asking, sharing, promises, boundaries; distinct memories/preferences; practical repair and friendship without transaction rewards for every kindness.
5. Fuller villager lives — QUEUED. Expand current business/visit routines into richer work/rest/friendship and weather/event schedules; improve continuity and save behavior.
6. Farming/equipment expansion — QUEUED. Crops, recipes, planting/watering/harvest upgrades and balanced progression.
7. Kingdom story — QUEUED. Fading premise, restoration milestones and the deferred arrival cutscene after the opening settles.
8. Exploration — QUEUED. Woodland, hills/mines and further kingdom locations, resources, discoveries and enterable buildings.
9. Customisation expansion — QUEUED. More hair/shirts/hats/colours; rustic-to-magical clothing; complete directional/action coverage before release.
10. Final interface/accessibility — QUEUED. Cohesive final UI, inventory/journal/building/wardrobe, readable text, touch controls, sound/motion/accessibility across devices.
11. Atmosphere — QUEUED. Environmental motion, lighting/weather, original sound/music, seasons and celebrations.
12. Release preparation — QUEUED. Real 7–11-year-old and adult playtests, clarity/pacing fixes, physical devices, performance, long sessions and save recovery. Prepare test materials before recruiting or messaging anyone; no external communication is authorised here.

Automated tests and visual checks accompany every phase rather than waiting until priority 12. Preserve the order instead of accumulating unrelated late-game features while the foundations are unfinished.
