## Gait repair
The first generated walk sheets repeated the lead foot. Imagegen corrections were inspected and rejected because side/rear gait still repeated. The shipped walking animation now uses a separate runtime limb rig with mirrored contact phases, retaining the canonical atlas head and torso. Rejected correction variants are not shipped. Work, idle and gesture frames use the original atlas.
